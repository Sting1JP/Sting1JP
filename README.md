# Stefano Ivan Stinga

Independent researcher and astrophotographer in Osaka, Japan. I work with public data from space missions and telescopes on exoplanet transit timing, supernovae and radio astronomy. I also make images from spacecraft data and from my own observations with remote telescopes.

### Software

- [**dss-precovery**](https://github.com/Sting1JP/dss-precovery): finds known, slow-moving Solar System objects on the Digitized Sky Survey scans of old photographic plates (POSS-I and UK Schmidt) and measures their positions against Gaia DR3. [doi:10.5281/zenodo.23805408](https://doi.org/10.5281/zenodo.23805408)
- [**tess-transit-times**](https://github.com/Sting1JP/tess-transit-times): measures the mid-transit times of known transiting planets in TESS light curves (the code behind the TESS times in the WASP-22 b note). [doi:10.5281/zenodo.23875329](https://doi.org/10.5281/zenodo.23875329)
